# 🚗 Сервис записи на ремонт и детейлинг автомобилей

Простое приложение для создания и управления заявками на ремонт и детейлинг автомобилей. Подходит для автосервисов и детейлинг-центров.

---

## 📋 Описание

Приложение позволяет клиентам оставлять заявки на ремонт или детейлинг, а администраторам — просматривать и управлять ими через удобный интерфейс.

### Создание заявки на ремонт
Клиент заполняет следующие поля:
1. Имя
2. Номер телефона
3. Модель автомобиля
4. Дата
5. Время
6. Описание проблемы

### Создание заявки на детейлинг
Клиент заполняет:
1. Имя
2. Номер телефона
3. Модель автомобиля
4. Дата
5. Время
6. Email

### Статистика
- Просмотр всех активных заявок
- При нажатии на заявку:
  - Возможность редактировать данные
  - Подтвердить выполнение
  - Удалить заявку
